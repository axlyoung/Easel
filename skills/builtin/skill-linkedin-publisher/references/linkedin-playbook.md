# LinkedIn 平台专家手册（AI 赛道）

> 经验规律，不是 LinkedIn 公开的算法参数。

## 分发怎么走

1. 帖子先推给一小部分一度人脉和关注者，看前 60–90 分钟的反应（“黄金一小时”）。
2. 有**有内容的评论**（不是 emoji）、停留时间长、被收藏/转发，就扩到二度、三度人脉和话题流。
3. 评论 > 转发 > 收藏 > 点赞。长评论和评论里的来回对话最值钱。
4. 外链（让人离开 LinkedIn）明显压分发，所以链接放第一条评论。
5. 同一个人 24 小时内连发两帖，第二帖会抢第一帖的流量。

近年 LinkedIn 更偏向“有专业知识的内容”，而不是泛励志和热点。
对 AI 创作者来说就是：**具体的工作场景 + 具体的工具 + 具体的结果**。

## Day 0 资料（发第一条之前做完）

| 项 | 怎么写 |
|---|---|
| 头像 | 清晰正面照，背景干净 |
| 横幅 | 一句话说你写什么，如 "Practical notes on working with AI agents" |
| Headline | 不只写职位："Engineer · Building with AI agents · Writing about what actually works" |
| About | 第一人称 3 段：我在做什么 / 我为什么写 AI / 你能从我这里得到什么 |
| Featured | 置顶 1 篇 Blogger 长文或最好的一条帖 |
| 经历 | 真实填写；不夸大头衔 |
| Creator mode / 话题 | 3–5 个话题标签：#AI #GenerativeAI #SoftwareEngineering 等 |

## 加人（邀请）规则

| 阶段 | 每天 | 每周 | 要求 |
|---|---|---|---|
| S0（前 2 周） | ≤10 | ≤50 | 每条附个性化留言（提到对方的一条具体内容） |
| S1 | ≤15 | <100 | 优先加评论过你、你评论过的人 |
| S2 | ≤20 | <100–150 | 待通过邀请不超过 200，定期撤回老邀请 |

大量邀请被忽略或被点“我不认识此人”，会触发邀请限制（需要输入对方邮箱才能加）。
不要用任何自动加人工具。

## 帖子模板

**实测帖**
```
[一个结果 + 一个数字，前 210 字符内]

[背景：我为什么做这件事，2 句]

[过程：做了什么，1 段]

[意外：哪里和预期不一样，1 段，最好有数字]

[我现在怎么做：具体到工具和步骤]

[一个读者能回答的问题]
```

**观点帖**
```
[一个具体的反常识判断]

[我为什么这么想：一次亲身经历]

[反方的道理（承认它）]

[我的结论 + 适用边界]

[问题]
```

## 帖子类型表现（经验）

| 类型 | 表现 | 说明 |
|---|---|---|
| 文档帖（PDF 轮播） | 高 | 停留时间长；工作流、对比、清单 |
| 文本 + 1 张真截图 | 高 | 截图要能看清，别用素材图 |
| 纯文本 | 中 | 写得好也能很好 |
| 外链帖 | 低 | 链接放评论 |
| 投票 | 中，但互动质量低 | 偶尔用 |
| 视频 | 看质量 | 竖屏、带字幕、前 3 秒有信息 |

## 会被限制的行为

- 自动化插件（自动访问、自动加人、自动发消息、抓取数据）
- engagement pod / 互赞群
- “评论 YES 拿资料”式诱导（被判为互动诱饵，降权）
- 群发相同的私信
- 发帖后立刻编辑多次（前 10 分钟别改）
- 编造职位、公司、成绩

## 数据回查

7 天后记录：impressions、reactions、comments、reposts、profile views、新增关注/人脉。
看 **评论数 / 曝光** 和 **主页访问**，不看点赞。
