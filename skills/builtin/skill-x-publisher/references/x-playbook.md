# X 平台专家手册（AI 赛道）

> 经验规律，不是 X 公开的算法参数。X 的推荐（For You）会改，以账号近 30 天自己的数据为准。

## 推荐看什么（按权重粗排）

| 信号 | 说明 | 怎么命中 |
|---|---|---|
| 回复 + 作者回回复 | 权重最高的一类互动；你回了评论者，这条对话会被持续推 | 发完 30 分钟内回每一条评论，回得比对方长 |
| 停留 / 点开 | 点开串推、展开长推、看图 | 第 1 条留一个“想知道后面”的口子；放真截图 |
| 转推 / 引用 | 转出去才有新受众 | 一个可以单独被引用的数字或判断 |
| 收藏 | 实用内容的信号 | 工作流、提示词、清单类 |
| 点赞 | 最弱 | 不要为它优化 |
| 负面信号 | “不感兴趣”、屏蔽、举报、秒划走 | 不标题党，不蹭无关热点 |

外链：带外链的帖子分发明显少于不带的（尤其非 Premium），所以链接放回复或串推最后一条。

## Day 0 清单（发第一条之前做完）

- 头像、横幅、显示名（真名或稳定的品牌名 + 一个领域词，如 *Hui · AI agents*）
- 简介一句话：我是谁 + 我写什么 + 证据（“shipping with AI agents daily; I post what breaks”）
- 置顶：一条自我介绍串推或你最好的一条实测
- 绑定邮箱和手机；开二次验证
- 关注 30–50 个真正想读的同领域账号（分 2–3 天关注完，不一次性）
- 可选：Premium（回复优先展示、长推、编辑；对新号冷启动帮助明显）

## 串推结构模板（实测类）

```
1  结论 + 最反常识的数字（必须单独成立）
---
2  我为什么做这个实验 / 背景，一句话
---
3  第一个具体发现 + [🖼 截图]
---
4  第二个发现（短，一句话也行）
---
5  踩坑：哪里坏了、花了多少时间/钱
---
6  我现在的做法（具体到工具和步骤）
---
7  一句判断 / 一个问题（链接从 S1 开始放这里或放回复）
```

长度起伏：别每条都一样长，第 4 条可以只有一句。

## 单推的 5 种 AI 赛道写法

| 写法 | 例 |
|---|---|
| 成本账 | "My AI bill last month: $187. 61% of it was one tool I opened twice." |
| 小实验 | "Asked 3 models to fix the same flaky test. Only one noticed the timezone bug." |
| 反常识 | "Shorter prompts got me better code. Not by a little." |
| 工作流 | "My morning: agent triages inbox → I read 6 emails instead of 70. Took 20 min to set up." |
| 事件 + 判断 | "New model dropped. Ran my 5 usual tasks. Faster, not smarter. Here's the one task it lost." |

## 发帖时间

| 读者 | 时段 |
|---|---|
| 美国 | 美东 8–10 点、12–13 点、17–19 点；周二到周四最好 |
| 欧洲 | 伦敦 8–10 点、12–14 点 |
| 中文 AI 圈 | 北京时间 9–11 点、20–23 点 |

固定 1–2 个时段，形成节奏。发完别马上离开，30 分钟内回评论。

## 会被限流 / 封号的行为

| 行为 | 后果 |
|---|---|
| 短时间大量关注/取关（follow churn） | 锁号、要求验证 |
| 重复或高度相似的回复/帖子 | 判为垃圾，回复被折叠 |
| hashtag >2、蹭无关热门 hashtag | 降权 |
| 新号私信陌生人带链接 | 私信功能被限，甚至封号 |
| @ 一串不认识的大号 | 被举报为骚扰 |
| 第三方工具自动点赞/关注/回复 | 违反平台自动化规则，封号 |
| 多号互相点赞转推 | 不真实行为（platform manipulation），批量封 |
| 用 AI 批量生成回复 | 回复质量差、相似度高，被折叠并降权 |

## 数据回查

每条发后 48–72 小时记录：impressions、engagement rate（互动/曝光）、profile visits、新增关注。
S0–S1 阶段不看点赞，看 **profile visits → follow** 的转化：主页和置顶不行，内容再好也留不住人。
